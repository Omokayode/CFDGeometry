## VS Code (local clone)

**File:** `cfd_geometry_quickstart.ipynb` — for developers with the repo checked out.

1. **File → Open Folder** → CFDGeometry repo root.
2. `python -m pip install -e ".[notebook,download]"` in `.venv`.
3. Select the **`.venv`** kernel and run the notebook.
